Why it does not leak

Privacy by construction, not by convention.

Transparent addresses are rejected at the API boundary. Disclosure is a key you hand out per payment, never the wallet.

node --import tsx
wallet.paymentProof(txid)
viewing key → merchant
reveals 1 of 8
on-chain: commitments onlydisclosed: —

t-addresses refused

send() and newAddress() throw on any transparent address. There is no code path that creates a transparent output.

Selective disclosure

paymentProof() proves one payment to one merchant. No seed, no balance, no other history.

Audited in CI

zcash-audit flags transparent-pool notes as critical and exits 2. Missing memos and dust get warnings.

Real vs mock

Exactly what is real, and what is not.

One API surface, two adapters. The wallet picks the real one when the platform supports it and tells you when it does not.
